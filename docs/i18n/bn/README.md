# Vidrado

**শান্ত ডেস্কটপ। স্বচ্ছ মন।**

Vidrado হলো macOS-এর একটি নেটিভ মেনু বার অ্যাপ, যা পেছনের উইন্ডোগুলো ঝাপসা ও ম্লান করে এবং সক্রিয় উইন্ডোটি পরিষ্কার রাখে। এটি সম্পূর্ণ আপনার Mac-এ চলে; কোনো অ্যাকাউন্ট, সাবস্ক্রিপশন, ট্র্যাকিং বা স্ক্রিন রেকর্ডিং নেই।

## সুবিধা

- পটভূমি সরাসরি ঝাপসা বা ম্লান করুন, অথবা দুটো প্রভাব একসঙ্গে ব্যবহার করুন; দ্রুত তীব্রতা বদলানোর স্লাইডার এবং হালকা, ভারসাম্যপূর্ণ ও গভীর মাত্রা রয়েছে।
- অ্যাপ ও Spaces-এর মধ্যে পরিবর্তন করলেও সক্রিয় উইন্ডো পরিষ্কার থাকে।
- প্রতিটি অ্যাপের জন্য নিয়ম: পেছনের উইন্ডো স্বয়ংক্রিয়ভাবে কোমল করুন, কোনো অ্যাপ পরিষ্কার রাখুন, অথবা সেটি সক্রিয় থাকলে মনোযোগের প্রভাব বিরত রাখুন। প্রকৃত অ্যাপ আইকন গ্রেস্কেলে দেখানো হয়।
- সব ডিসপ্লেতে অথবা শুধু সক্রিয় ডিসপ্লেতে মনোযোগের প্রভাব ব্যবহার করুন; সারিবদ্ধ উইন্ডো ও Split View বজায় রাখুন।
- পূর্ণ পর্দা, স্ক্রিন শেয়ারিং, অবিরাম ক্যাপচার বা ডিসপ্লে মিররিংয়ের সময় বিরতির বিকল্প।
- নিজের মতো করে নির্ধারণযোগ্য গ্লোবাল শর্টকাট, কার্সর ঝাঁকানোর ঐচ্ছিক অঙ্গভঙ্গি এবং লগইনের সময় চালু হওয়ার সুবিধা।
- সংরক্ষিত প্রিসেট ও স্থানীয় পছন্দসমূহ।
- ইন্টারফেসের তেরোটি ভাষা। Vidrado সিস্টেমের প্রধান ভাষা অনুসরণ করে এবং অসমর্থিত ভাষার ক্ষেত্রে ইংরেজি ব্যবহার করে। আরবি ও উর্দুতে ডান থেকে বাম বিন্যাস ব্যবহৃত হয়।

## ইনস্টল করুন

**macOS 14 বা পরবর্তী সংস্করণ** প্রয়োজন। [Releases](https://github.com/tonhadaplaces/vidrado/releases) থেকে DMG ডাউনলোড করুন, সেটি খুলুন এবং **Vidrado**-কে **Applications**-এ টেনে আনুন।

বর্তমান বিতরণে **ad hoc স্বাক্ষর** ব্যবহৃত হয় এবং এটি **Apple দ্বারা নোটারাইজ করা নয়**। এই রিপোজিটরি থেকে ডাউনলোড করা Vidrado অ্যাপ খুলতে macOS বাধা দিলে, শুধু ওই অ্যাপের কোয়ারেন্টাইন অ্যাট্রিবিউট সরিয়ে দিন:

```sh
xattr -dr com.apple.quarantine /Applications/Vidrado.app
```

তারপর Vidrado আবার খুলুন। এই কমান্ড অ্যাপকে নোটারাইজ করে না এবং পুরো সিস্টেমের Gatekeeper সেটিংস বদলায় না। চাইলে স্থানীয়ভাবে বিল্ড করতে পারেন। স্বয়ংক্রিয় রিলিজের DMG **Apple silicon ও Intel** সমর্থন করে।

## ব্যবহার

মনোযোগের নিয়ন্ত্রণ খুলতে মেনু বারে একটির ওপর আরেকটি থাকা উইন্ডোর আইকনে ক্লিক করুন। **⌥⌘B** দিয়ে যেকোনো জায়গা থেকে মনোযোগের প্রভাব চালু বা বন্ধ করা যায়। মেনু বারের আইকনে রাইট-ক্লিক বা Option চেপে ক্লিক করলেও এটি চালু বা বন্ধ হয়।

স্লাইডারের বোতাম বা **⌘,** দিয়ে পছন্দসমূহ খুলুন। **কিছু অ্যাপ পরিষ্কার রাখুন** থেকে অ্যাপ বেছে নিন। অতিরিক্ত প্রভাবের স্লাইডার, প্রিসেট ও কার্সরের অঙ্গভঙ্গি **আরও বিকল্প**-এ রয়েছে। **⌘W** দিয়ে সেটিংসের উইন্ডো বন্ধ করুন; Vidrado মেনু বারে চলতে থাকবে। **⌘Q** দিয়ে অ্যাপ বন্ধ হয়।

## বিল্ড ও পরীক্ষা

Swift 5.9 বা নতুন সংস্করণের সঙ্গে Xcode অথবা Command Line Tools ব্যবহার করুন:

```sh
git clone git@github.com:tonhadaplaces/vidrado.git
cd vidrado
swift run Vidrado --settings
./scripts/build.sh
swift test
./scripts/test.sh
./scripts/package.sh
```

`build.sh`, `dist/Vidrado.app` বিল্ড করে ও স্বাক্ষর করে। `package.sh`, `dist/Vidrado.dmg` এবং তার SHA-256 চেকসম তৈরি করে। ডিফল্ট বিল্ড Mac-এর আর্কিটেকচারের জন্য তৈরি হয়। Apple silicon ও Intel-এর জন্য বিল্ড করতে `VIDRADO_UNIVERSAL=1 ./scripts/package.sh` ব্যবহার করুন।

`swift test` মূল XCTest পরীক্ষাগুলো চালায়। সম্পূর্ণ পরীক্ষার স্ক্রিপ্ট debug ও release কনফিগারেশনে নেটিভ যাচাইও চালায়। এসব যাচাইয়ের জন্য আনলক করা গ্রাফিক্যাল সেশন, সামনে একটি সাধারণ উইন্ডো এবং Vidrado বন্ধ থাকা প্রয়োজন। GitHub CI মূল পরীক্ষা চালায় এবং অ্যাপের বিল্ড যাচাই করে; গ্রাফিক্যাল যাচাই স্থানীয়ভাবে চলে।

অবদান রাখার আগে [রিপোজিটরির নির্দেশিকা](../../../AGENTS.md) ও [যাচাই সংক্রান্ত নোট](../../../TESTING.md) পড়ুন। পুল রিকোয়েস্ট ব্যবহার করুন: `main`-এর জন্য অন্তত একটি অনুমোদন, সফল CI এবং পর্যালোচনার সব আলোচনার নিষ্পত্তি প্রয়োজন।

## স্বয়ংক্রিয় রিলিজ

সংস্করণের পরিবর্তনগুলো (`Resources/Info.plist`-এ `CFBundleShortVersionString` ও `CFBundleVersion`) একটি পুল রিকোয়েস্টে অন্তর্ভুক্ত করুন। অনুমোদন ও `main`-এ মার্জের পর, সেই কমিটে ট্যাগ দিন:

```sh
git switch main
git pull --ff-only origin main
git tag v1.0.0
git push origin v1.0.0
```

`1.0.0`-এর জায়গায় প্রকাশ করা সংস্করণের নম্বর লিখুন। GitHub Actions কোড পরীক্ষা করে, ইউনিভার্সাল অ্যাপ বিল্ড করে, স্বাক্ষরিত বান্ডল ও DMG যাচাই করে এবং DMG-এর সঙ্গে তার SHA-256 চেকসম প্রকাশ করে। ওয়ার্কফ্লো যাচাই করে যে ট্যাগটি `main`-এ আছে এবং অ্যাপের সংস্করণের সঙ্গে মেলে। Apple Developer-এর সশুল্ক অ্যাকাউন্টের পরিচয়তথ্যের প্রয়োজন নেই; রিলিজে ওপরে বলা ad hoc স্বাক্ষরের সীমা বহাল থাকে।

## গোপনীয়তা ও প্রযুক্তিগত সীমা

Vidrado উইন্ডোর মেটাডেটা পড়ে এবং সক্রিয় উইন্ডোর নিচে এমন ওভারলে রাখে যার সঙ্গে ইন্টারঅ্যাক্ট করা যায় না। macOS-এর কম্পোজিটর পেছনের চলমান বিষয়বস্তুতে প্রভাব প্রয়োগ করে। এটি আপনার নথি পড়ে না, পর্দার ফ্রেম ক্যাপচার করে না, নেটওয়ার্কের মাধ্যমে তথ্য পাঠায় না এবং Accessibility অনুমতির প্রয়োজন হয় না।

ঝাপসা করা, ক্লিপিং, শেয়ারিং শনাক্তকরণ এবং Spaces-এর মেটাডেটার জন্য প্রাইভেট SkyLight ফাংশন ব্যবহার করা হয়, যেগুলো রানটাইমে খুঁজে নেওয়া হয়। macOS আপডেটের সঙ্গে এগুলোর প্রাপ্যতা বদলাতে পারে, এবং এই বাস্তবায়ন Mac App Store-এর জন্য উপযুক্ত নয়। পাশাপাশি সাজানো উইন্ডো শনাক্ত করতে জ্যামিতি ব্যবহার করা হয়। প্রভাবটি দৃশ্যমান উপস্থাপনার জন্য; রেকর্ডিংয়ে সংবেদনশীল বিষয়বস্তু লুকানোর উপায় নয়।
