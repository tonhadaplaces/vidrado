# Vidrado

**سطح مكتب أهدأ. ذهن أكثر صفاءً.**

Vidrado تطبيق أصلي لشريط القوائم في macOS، يموّه نوافذ الخلفية ويعتّمها مع إبقاء النافذة النشطة واضحة. يعمل بالكامل على جهاز Mac الخاص بك، دون حساب أو اشتراك أو تتبّع أو تسجيل للشاشة.

## الميزات

- تمويه مباشر للخلفية أو تعتيمها أو الجمع بينهما، مع منزلق لضبط الشدة بسرعة ومستويات خفيف ومتوازن وعميق.
- تبقى النافذة النشطة واضحة أثناء التنقل بين التطبيقات وSpaces.
- قواعد لكل تطبيق: تلطيف نوافذ الخلفية تلقائيًا، أو إبقاء تطبيق واضحًا، أو إيقاف التركيز مؤقتًا عندما يكون التطبيق نشطًا. تظهر أيقونات التطبيقات الحقيقية بتدرّج رمادي.
- تطبيق التركيز على جميع الشاشات أو الشاشة النشطة فقط، مع الحفاظ على النوافذ المصطفّة وSplit View.
- خيار إيقاف التركيز مؤقتًا أثناء وضع ملء الشاشة أو مشاركة الشاشة أو الالتقاط المستمر أو انعكاس الشاشة.
- اختصار عام قابل للتخصيص، وإيماءة اختيارية بهزّ المؤشر، وتشغيل عند تسجيل الدخول.
- إعدادات مسبقة محفوظة وتفضيلات محلية.
- ثلاث عشرة لغة للواجهة. يتبع Vidrado لغة النظام الأساسية، ويستخدم الإنجليزية عند عدم دعم تلك اللغة. تستخدم العربية والأردية تخطيطًا من اليمين إلى اليسار.

## التثبيت

يتطلب **macOS 14 أو أحدث**. نزّل ملف DMG من [Releases](https://github.com/tonhadaplaces/vidrado/releases)، وافتحه، ثم اسحب **Vidrado** إلى **Applications (التطبيقات)**.

يستخدم التوزيع الحالي **توقيعًا من نوع ad hoc**، وهو **غير موثّق لدى Apple**. إذا منع macOS فتح تطبيق Vidrado الذي نزّلته من هذا المستودع، فأزل سمة العزل من ذلك التطبيق فقط:

```sh
xattr -dr com.apple.quarantine /Applications/Vidrado.app
```

ثم افتح Vidrado مجددًا. لا يوثّق هذا الأمر التطبيق لدى Apple، ولا يغيّر إعدادات Gatekeeper على مستوى النظام. يمكنك بناء التطبيق محليًا إن رغبت. تدعم ملفات DMG للإصدارات التلقائية **Apple silicon وIntel**.

## الاستخدام

انقر على أيقونة النافذتين المتداخلتين في شريط القوائم لفتح عناصر التحكم بالتركيز. يبدّل **⌥⌘B** تشغيل التركيز وإيقافه من أي مكان. ويؤدي النقر بزر الفأرة الأيمن أو النقر مع الضغط على Option على أيقونة شريط القوائم إلى تبديله أيضًا.

افتح التفضيلات باستخدام زر المنزلقات أو **⌘,**. اختر التطبيقات ضمن **إبقاء بعض التطبيقات واضحة**. توجد منزلقات التأثيرات الإضافية والإعدادات المسبقة وإيماءة المؤشر ضمن **المزيد من الخيارات**. أغلق نافذة الإعدادات باستخدام **⌘W**؛ يستمر Vidrado بالعمل في شريط القوائم. يُنهي **⌘Q** التطبيق.

## البناء والاختبار

استخدم Xcode أو Command Line Tools مع Swift 5.9 أو أحدث:

```sh
git clone git@github.com:tonhadaplaces/vidrado.git
cd vidrado
swift run Vidrado --settings
./scripts/build.sh
swift test
./scripts/test.sh
./scripts/package.sh
```

يبني `build.sh` الحزمة `dist/Vidrado.app` ويوقّعها. وينتج `package.sh` الملف `dist/Vidrado.dmg` وبصمة SHA-256 الخاصة به. يستهدف البناء الافتراضي بنية جهاز Mac. استخدم `VIDRADO_UNIVERSAL=1 ./scripts/package.sh` للبناء لكل من Apple silicon وIntel.

يشغّل `swift test` اختبارات XCTest للمنطق الأساسي. كما يشغّل سكربت الاختبار الكامل فحوصًا أصلية في إعدادَي debug وrelease. تتطلب هذه الفحوص جلسة رسومية غير مقفلة، ونافذة عادية في المقدمة، وإيقاف Vidrado. يشغّل GitHub CI الاختبارات الأساسية ويتحقق من بناء التطبيق؛ وتُجرى الفحوص الرسومية محليًا.

اقرأ [إرشادات المستودع](../../../AGENTS.md) و[ملاحظات التحقق](../../../TESTING.md) قبل المساهمة. استخدم طلب سحب: يتطلب `main` موافقة واحدة على الأقل، واجتياز CI، وحل جميع نقاشات المراجعة.

## الإصدارات التلقائية

أدرج تغييرات الإصدار (`CFBundleShortVersionString` و`CFBundleVersion` في `Resources/Info.plist`) في طلب سحب. بعد الموافقة والدمج في `main`، أضف وسمًا إلى ذلك الالتزام:

```sh
git switch main
git pull --ff-only origin main
git tag v1.0.0
git push origin v1.0.0
```

استبدل `1.0.0` برقم الإصدار الذي تريد نشره. يختبر GitHub Actions الشفرة، ويبني نسخة موحّدة من التطبيق تدعم البنيتين، ويتحقق من الحزمة الموقّعة وملف DMG، وينشر ملف DMG وبصمة SHA-256 الخاصة به. يتحقق سير العمل من أن الوسم يقع على `main` ويطابق إصدار التطبيق. لا حاجة إلى بيانات اعتماد Apple Developer المدفوعة؛ تبقى الإصدارات خاضعة لقيود توقيع ad hoc المذكورة أعلاه.

## الخصوصية والحدود التقنية

يقرأ Vidrado البيانات الوصفية للنوافذ ويضع طبقات غير تفاعلية تحت النافذة النشطة. يطبّق مركّب macOS التأثير على محتوى الخلفية المباشر. لا يقرأ مستنداتك، ولا يلتقط إطارات الشاشة، ولا يرسل بيانات عبر الشبكة، ولا يتطلب إذن تسهيلات الاستخدام.

يعتمد التمويه والقصّ واكتشاف المشاركة والبيانات الوصفية لـSpaces على دوال SkyLight خاصة يجري تحديدها أثناء التشغيل. قد يتغير توفرها مع تحديثات macOS، وهذا التنفيذ غير مناسب لـMac App Store. يستخدم اكتشاف النوافذ المبلّطة معلومات هندسية. التأثير بصري، وليس وسيلة لإخفاء المحتوى الحساس في التسجيلات.
