# Vidrado

**Спокойнее рабочий стол. Яснее мысли.**

Vidrado — нативное приложение для строки меню macOS, которое размывает и затемняет фоновые окна, сохраняя активное окно чётким. Оно полностью работает на вашем Mac, без учётной записи, подписки, отслеживания или записи экрана.

## Возможности

- Размытие, затемнение или оба эффекта для фоновых окон в реальном времени, с удобным ползунком интенсивности и уровнями «Лёгкий», «Сбалансированный» и «Глубокий».
- Активное окно остаётся чётким при переключении между приложениями и пространствами Spaces.
- Правила для отдельных приложений: автоматически смягчайте фоновые окна, сохраняйте приложение чётким или приостанавливайте концентрацию, пока оно активно. Настоящие значки приложений отображаются в оттенках серого.
- Применяйте концентрацию на всех дисплеях или только на активном; сохраняйте выровненные окна и Split View.
- Необязательные паузы при полноэкранном режиме, демонстрации экрана, непрерывном захвате или видеоповторе дисплеев.
- Настраиваемое глобальное сочетание клавиш, необязательный жест встряхивания курсора и запуск при входе в систему.
- Сохранённые предустановки и локальные настройки.
- Тринадцать языков интерфейса. Vidrado использует основной язык системы и переключается на английский для неподдерживаемых языков. Для арабского и урду используется расположение интерфейса справа налево.

## Установка

Требуется **macOS 14 или новее**. Скачайте DMG из раздела [Releases](https://github.com/tonhadaplaces/vidrado/releases), откройте его и перетащите **Vidrado** в **Программы**.

Текущая сборка использует **подпись ad hoc** и **не прошла нотариализацию Apple**. Если macOS не позволяет открыть приложение Vidrado, скачанное из этого репозитория, удалите атрибут карантина только у этого приложения:

```sh
xattr -dr com.apple.quarantine /Applications/Vidrado.app
```

Затем снова откройте Vidrado. Эта команда не выполняет нотариализацию приложения и не меняет настройки Gatekeeper для всей системы. При желании соберите приложение локально. DMG из автоматических релизов поддерживают **Apple silicon и Intel**.

## Использование

Нажмите значок перекрывающихся окон в строке меню, чтобы открыть элементы управления концентрацией. **⌥⌘B** включает и выключает концентрацию из любого приложения. Щелчок правой кнопкой мыши или щелчок с зажатой Option по значку в строке меню также переключает её.

Откройте настройки кнопкой с ползунками или сочетанием **⌘,**. Выберите приложения в разделе **Оставить некоторые приложения чёткими**. Дополнительные ползунки эффектов, предустановки и жест курсора находятся в разделе **Другие параметры**. Закройте окно настроек сочетанием **⌘W**; Vidrado продолжит работать в строке меню. **⌘Q** завершает работу приложения.

## Сборка и тестирование

Используйте Xcode или Command Line Tools со Swift 5.9 или новее:

```sh
git clone git@github.com:tonhadaplaces/vidrado.git
cd vidrado
swift run Vidrado --settings
./scripts/build.sh
swift test
./scripts/test.sh
./scripts/package.sh
```

`build.sh` собирает и подписывает `dist/Vidrado.app`. `package.sh` создаёт `dist/Vidrado.dmg` и его контрольную сумму SHA-256. По умолчанию сборка предназначена для архитектуры текущего Mac. Используйте `VIDRADO_UNIVERSAL=1 ./scripts/package.sh` для сборки под Apple silicon и Intel.

`swift test` запускает тесты ядра на XCTest. Полный сценарий тестирования также выполняет нативные проверки в конфигурациях debug и release. Для этих проверок требуется разблокированный графический сеанс, обычное окно на переднем плане и остановленное приложение Vidrado. CI в GitHub запускает тесты ядра и проверяет сборку приложения; графические проверки выполняются локально.

Перед внесением изменений прочитайте [Правила репозитория](../../../AGENTS.md) и [Примечания по проверке](../../../TESTING.md). Используйте pull request: ветка `main` требует хотя бы одного одобрения, успешного прохождения CI и разрешения всех обсуждений ревью.

## Автоматические релизы

Включите изменения версии (`CFBundleShortVersionString` и `CFBundleVersion` в `Resources/Info.plist`) в pull request. После одобрения и слияния в `main` создайте тег для этого коммита:

```sh
git switch main
git pull --ff-only origin main
git tag v1.0.0
git push origin v1.0.0
```

Замените `1.0.0` на выпускаемую версию. GitHub Actions тестирует код, собирает универсальное приложение, проверяет подписанный пакет и DMG, а затем публикует DMG вместе с его контрольной суммой SHA-256. Рабочий процесс проверяет, что тег находится на `main` и соответствует версии приложения. Данные платной учётной записи Apple Developer не требуются; релизы сохраняют описанные выше ограничения подписи ad hoc.

## Конфиденциальность и технические ограничения

Vidrado читает метаданные окон и размещает неинтерактивные наложения под активным окном. Композитор macOS применяет эффект к фоновому содержимому в реальном времени. Приложение не читает ваши документы, не захватывает кадры экрана, не отправляет данные по сети и не требует разрешения на Универсальный доступ.

Размытие, обрезка, обнаружение демонстрации экрана и метаданные Spaces используют закрытые функции SkyLight, адреса которых определяются во время выполнения. Их доступность может измениться с обновлениями macOS, и эта реализация не подходит для Mac App Store. Обнаружение окон, расположенных плиткой, использует геометрию. Эффект является визуальным и не позволяет скрывать конфиденциальное содержимое в записях.
